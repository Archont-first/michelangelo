# Анимации интерфейса (Lottie)

| файл | где | перекраска (`web/lib/lottie.ts`) |
|---|---|---|
| `cube-light.json` | индикатор загрузки, разбора, экспорта (светлая тема) | линии — красный `#A4302A`, грани — молочный |
| `cube-dark.json` | то же, тёмная тема (`prefers-color-scheme: dark`) | линии — `#E8928A`, грани — почти чёрный |
| `david.json` | страница входа по коду доступа | жёлтые — в оттенки красного бренда (светлые → светлее, тёмные → темнее), чёрный — почти чёрный |

Источник — LottieFiles, копии из `references/anim/` без изменений: цвета меняются при загрузке, в копии данных.
Лицензия — Lottie Simple License (бесплатные, коммерческое использование разрешено), подробно — [LICENSE.md](LICENSE.md).

Плеер — `lottie-web` (MIT), light-сборка (`lottie_light`, только SVG), грузится лениво (`web/app/lottie-anim.tsx`):
только на экранах, где анимация видна; закончилась загрузка/разбор/экспорт — `destroy()`.
`prefers-reduced-motion` — статичный первый кадр.
